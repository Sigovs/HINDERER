Design System

Every swatch, specimen and control below is rendered by the site's own stylesheets. Change a value in tokens.css and this page moves with the site — it cannot drift, because there is nothing here to drift from. Written to be handed to a developer: the rules are stated, the exceptions are named, and what the system does not yet have is at the bottom.

Rules a change has to keep

Five, and they are the reason the rest of this page can be trusted. Each one is mechanically checkable — if a change breaks one, it will show up in a grep, not in a code review a week later.

The cascade

FileOwnsMust never contain
tokens.cssEvery value in the systemA selector other than :root
system.cssReset, layout primitives, a11y utilitiesAnything with a look
main.cssComponents, in page orderA raw colour, size, or interval
display-oswald.cssThe display voice, applied lastNew components

Load order is fixed. ds.css loads after all four and dresses this page only.

1 · No raw values below tokens.css. No hex, no rgb(31 29 25 / .5), no margin-top: 37px, no line-height: 1.45. If the value you want is not on a scale, either the value is wrong or the scale needs a documented addition — decide which, and write the reason in the token's comment. Two additions were made this way and both say so: --text-price and --text-spine.

2 · Alpha comes from a channel token, never from a new colour. A hex cannot be given an alpha, so every colour used translucently is also published as bare channels: rgb(var(--bg-rgb) / 0.55). Writing the numbers out is how the page ended up with two near-blacks nobody chose.

3 · A token that nothing uses is deleted, not kept "for later". An API that resolves to something no one has ever seen is worse than a missing one. Two shadow tokens and three spacing aliases were removed under this rule; where an unused token is deliberate, its comment says why (--ease-in is the exit half of a pair).

4 · Interval by relationship, not by eye. Reach for --space-text, --space-text-obj, --space-block and the two CTA intervals first. A gap picked straight off the raw scale gets picked again, differently, three sections later — which is exactly how the interval above a set of actions once existed as 24, 48, 72 and 96 at the same time.

5 · Contrast is computed, not eyeballed, and recorded on the line. Every colour token carries its ratio against the ground it actually sits on. Copper --accent is 3.67:1 — legal as display type at 24px and up, and as a solid fill; below 24px the text step --accent-ink is the only copper allowed.

Colour

Every value is measured from the Figma file, and its contrast ratio is recorded against the ground it actually sits on. There is no neutral black anywhere in the system — beside this warm ground, #000 reads blue, which is the exact cheapness the near-black was chosen to avoid.

Type

Three voices, each with a job the other two cannot do. Oswald announces; Inter Tight informs — its tabular figures are why the spec plates align; Playfair values. Weight is size-dependent: stems grow with the type, so the display tier takes the lightest weight. Setting one weight across the whole ramp is what makes display type read fat.

The three voices and what each is allowed to say

VoiceTokenRoles — and only these
Oswald --font-display Headlines, section titles and sub-lines, button labels, nav, card status, contact labels and the spine.
Inter Tight --font-body All reading: leads, body, notes, card titles, metadata, figures.
Playfair Display --font-serif .vehicle__price — one role, nothing else.

The serif is bounded to the price. In an auction catalogue the lot's price is set in a serif while the rubrics and the metadata stay sans — the change of face is what marks what the object costs apart from how the page is organised. It briefly also set the inventory's sub-line, which gave that one section a heading unlike every other section on the site; that line is now .section-sub like all the others. A section wanting a second rank under its title uses .section-sub. Adding a second serif role is a change to the system, not a local decision.

Six leading steps and seven tracking steps, and they are the only ones. Before this pass there were four leading tokens and ten different values in the CSS — which is how .lead ended up at 1.55 and the paragraph beside it at 1.45.

Uppercase stops at the display and label tiers. Caps remove the ascender and descender variation the eye uses to recognise word shapes, which measurably slows reading — so it never reaches a lead, a body or a caption. That is why the button labels are caps and the paragraph is not.

Space

A 4px base. The named distances are the point: an interval is chosen by relationship, not by eye. A gap taken straight from the raw scale gets taken again, differently, three sections later — which is exactly how the interval above a set of actions once existed as 24, 48, 72 and 96 at once.

Named rhythm — reach for these first

Text → its own body var(--space-text) 12
Text → object or control var(--space-text-obj) 24
Block → next block var(--space-block) 64

Internal gaps stay smaller than external ones, so a group reads as a group before it reads as a list of parts.

Content → CTA — two intervals, and only two

After prose var(--gap-cta-text) 48
After a grid, strip or rail var(--gap-cta-grid) 64

A paragraph ends softly — ragged right edge, open descenders — so 48 reads as the next step of one thought. A card grid ends on a hard edge with borders and shadow, and at 48 the button sticks to it and reads as one more card. Anything else picking a third value is a bug, not a decision.

Direction comes from the value: left, right, up. Without JS every element is simply visible — the reveal is an enhancement and never a gate on content.

Form controls

Built as a set for the inventory page rather than invented inside it — a control designed on one screen is how a second visual language gets in. One ground, one border, one focus behaviour, declared once, so a select and a text input cannot drift apart. Every one clears the 44px target floor — including the range handles, whose 24px rail is the drawing and whose 44px box is the target.

The reset that had to come first. Controls do not inherit type from their ancestor — every browser substitutes its own UI font at its own size, and this page was rendering its buttons in 13px Arial: a fourth voice nobody chose, arriving through a default rather than a decision, and under the 14px floor as well. button, input, select, textarea, optgroup { font: inherit } lives in system.css so the next control added does not have to remember it.

Text, number and select

.field · .field__label · .control · .field-pair. The select's UA arrow cannot be styled, so it is removed and redrawn as a caret in the page's own ink — inline SVG in a data URI, because a stylesheet cannot reach an icon file and still be one request.

Range — two handles, one rail

.range — two native range inputs stacked on one rail, not a scripted widget. Each handle is a real slider with its own label, operable from the keyboard and announced with its value, which no div-and-mousemove version manages.

Three things it must keep. The handles cannot cross — a "from" above its "to" is a query that can never match, and the control should refuse it rather than quietly return nothing. A handle resting on its extreme writes nothing into its field, because "no preference" must not silently become a bound. And it is paired with its From/To fields both ways: dragging writes the number, typing moves the handle.

Responsive

Four breakpoints, and a new one needs a reason. Small screens get less space, never none — the proportional relationships set at desktop hold at every width, and the gutter never goes below 24px.

QuerypxWhat changes
min-width: 62rem992Desktop. Header grows to 136px, gallery becomes the mosaic, scenes are held.
max-width: 61.99rem< 992Nav collapses behind the 44px toggle; the brand slot follows the mark instead of holding 180px.
max-width: 47.99rem< 768One column. The hero swaps to its portrait frame.
max-width: 23.5rem< 376The counter keeps its number and loses its words.

The hero is art-directed, not resized. The 1920×796 landscape crop has nothing left of the car once the frame turns portrait, so the phone gets its own 440×956 file where the car sits in the upper third and the ground falls away beneath it — which is where the headline and the two tall CTAs land. One <picture>, so only the matching file is fetched, and the two preload links carry the same media conditions so a phone never spends its first bytes on the image it will not paint.

Three masses in the header, and below 376px one has to give. The counter loses its label rather than the identity being reduced to an illegible 51px — and it is hidden the accessible way, so a screen reader still reads "My Collection / 03".

Known gaps

What this system does not yet have. A specimen page that only shows the good parts stops being useful the moment someone trusts it.

No typographic roles as classes. Figma carries nine text styles (display/hero, body/small, control/button…); CSS has no equivalent — type is declared inside each component. So one style change in Figma becomes a hunt through the component list here, and the same role can drift apart in two places without anything catching it. The size, leading and tracking ramps above are now single-source, which removes most of the risk but not the cause.

.vehicle__title is not on the h3 ramp. In Figma the card title uses display/h3 (Oswald 28px); in code it is the body voice at --text-lead. They were never reconciled, and the card was rebuilt around the code version — so this is a decision waiting to be made, not a bug waiting to be fixed.

Buttons speak louder than block headings. --text-btn tops out at 23px and --text-h3 at 28, but a button label is caps and a heading is not, so on the page the control reads larger than the heading above it. Unresolved.

Two measures run long. .spec-list__body and .nationwide__body sit near 92–94 characters against the 65–75 norm; --measure is not applied to either.

Section rhythm has no variation. Every section is separated by exactly the same interval, so a ten-section page has no phrasing — nothing groups, nothing breathes differently. And two full-screen held scenes (Trade In, Nationwide) are built identically and together take roughly 40% of the page height.

The reviews rail is not covered by prefers-reduced-motion. Its drag and its arrow travel still animate when the OS asks for less motion. Everything else on the page is switched off.

Content is placeholder. One vehicle photograph stands in for every card on both the home page and the inventory page, and the titles, prices, mileage and stock numbers are not a real feed. Two section images ship uncompressed at 1.7MB and 2.0MB.
