Colour

Every value is measured from the Figma file, and its contrast ratio is recorded against the ground it actually sits on. Copper clears 3:1 only as large type, which is why a second copper step exists for anything under 24px.

Type

Two voices, each with a job the other cannot do. Oswald carries headline mass; Inter Tight carries reading and data — its tabular figures are why the spec plates align. Weight is size-dependent: stems grow with the type, so the display tier does not take the heaviest weight. Setting one weight across the whole ramp is what makes display type read fat.

Uppercase stops at the display and label tiers. Caps remove the ascender and descender variation the eye uses to recognise word shapes, which measurably slows reading — so it never reaches a lead, a body or a caption. That is why the button labels above are caps and the paragraph is not.

Space

A 4px base. The three named distances are the point: an interval is chosen by relationship, not by eye. A gap taken straight from the raw scale gets taken again, differently, three sections later — which is exactly how the interval above a set of actions once ended up written as both 48px and 64px.

Named rhythm — reach for these first

Text → its own body var(--space-text) 12
Text → object or control var(--space-text-obj) 24
Block → next block var(--space-block) 64

Internal gaps stay smaller than external ones, so a group reads as a group before it reads as a list of parts.

Elevation

A shadow is a claim about elevation, so only things that genuinely sit above something else carry one. Everything that sits in the page is separated by a hairline and a tonal step instead — which is also what keeps a dark page from going mushy.

Buttons

One primary action per view. Copper is the primary, slate is the parallel secondary, ghost is the tertiary. Labels are uppercase — every one is two to four words, which is where caps are safe.

Known gaps

What this system does not yet have. A specimen page that only shows the good parts stops being useful the moment someone trusts it.

No typographic roles as classes. Figma carries nine text styles (display/hero, body/small, control/button…); CSS has no equivalent — type is declared inside each component. So one style change in Figma becomes a hunt through 182 component classes here, and the same role can drift apart in two places without anything catching it.

.vehicle__title is not on the h3 ramp. In Figma the card title uses display/h3 (Oswald 28px); in code it is body voice at 14px. They were never reconciled.

No form controls. Figma has an Input Field component with a focus ring; the site has no form yet, so nothing here implements it.

No motion specimens. The duration and easing scale exists in tokens (--dur-1…4, --ease-out), but nothing on this page demonstrates it.
